# Contexto Académico y Universitario del Proyecto MINER CLC

> Categoría: Proyecto Universitario / Ingeniería. Información académica, alcance institucional y objetivos del software.

## Información del Proyecto Universitario
- **Nombre del Proyecto:** MINER CLC (Sistema de Monitoreo de Gases y Ventilación Minera).
- **Ámbito:** Proyecto de grado / ingeniería aplicada para minería subterránea.
- **Ubicación de referencia:** Sutatausa, Cundinamarca, Colombia.
- **Objetivo General:** Desarrollar un sistema integral de software y hardware simulado para el monitoreo en tiempo real de gases nocivos, automatización del sistema de ventilación y gestión preventiva de alertas en operaciones mineras.
- **Arquitectura:** 
  - Frontend: Flutter (multiplataforma Web y Escritorio).
  - Backend API: Node.js con funciones serverless y endpoints RAG para asistencia inteligente con Gemini.
  - Base de Datos: PostgreSQL para persistencia transaccional y auditoría.
- **Alcance Académico:** Demostración de soluciones de automatización e inteligencia artificial aplicada al sector minero, alineado a normas de seguridad y salud en el trabajo.

## English Summary / Academic Overview
- **Project Title:** MINER CLC Underground Mining Monitoring & Ventilation System.
- **Academic Scope:** University engineering project focused on subterranean mine safety.
- **Key Features:** Real-time gas tracking (CO, CH4, O2, CO2, H2S), automated ventilation control, alert dispatching, and AI assistant integration using Retrieval-Augmented Generation (RAG) and Google Gemini.
